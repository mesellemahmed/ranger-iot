# LKH Unicast Transport Baseline

This baseline combines the symbolic Logical Key Hierarchy planner with the deterministic multi-hop shortest-path transport.

## Purpose

The baseline deliberately separates two costs:

- **logical ciphertexts**: unique LKH key-update ciphertexts generated by the key hierarchy;
- **physical transmissions**: link-layer transmissions required to deliver routed copies to all covered recipients.

A single logical LKH ciphertext can cover multiple members cryptographically. In this baseline, the ciphertext is copied and routed independently to each covered member. This is intentionally conservative and does not model multicast or flooding gains.

## Acceptance semantics

A member advances to the new group epoch only after it has received every LKH update required for its key path in that epoch. Updates may arrive out of order and are buffered symbolically.

## Loss semantics

There is no recovery or retransmission in this baseline. Any dropped routed copy can leave one or more members unsynchronized. Recovery and loss-resilient dissemination are separate protocol mechanisms evaluated later.

## Metrics

The baseline exposes:

- logical ciphertext count;
- routed copy count;
- link-layer transmissions;
- bytes transmitted;
- manager transmissions;
- T50, T95, and T100 convergence times.

This baseline is not intended to represent an optimized multicast LKH deployment. It provides a controlled reference point before adding network-aware dissemination.
