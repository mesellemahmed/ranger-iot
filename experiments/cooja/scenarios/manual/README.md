# Manual Cooja scenarios

This directory stores Cooja `.csc` scenarios created or inspected with the
interactive GUI.

Use the GUI only for scenario construction, debugging, visualization and
manual inspection. Publication experiments remain scripted and headless via
Docker Compose so that researchers can reproduce them automatically.

When saving a scenario from Cooja, save it under:

`/workspace/experiments/cooja/scenarios/manual/`

Meaningful scenarios should be committed to Git with descriptive names.
